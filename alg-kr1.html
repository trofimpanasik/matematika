Подготовка к контрольной «Степень с натуральным и целым показателями»

Всё, что нужно знать по главе 1, на одной странице: определения, свойства, стандартный вид. Пройди тест и реши типовые задания — они похожи на задания контрольной.

ШпаргалкаТестТиповые задания

Шпаргалка

Определения

a^n = a · a · … · a (n множителей)
a^1 = a,  a^0 = 1 (a ≠ 0)
a−n = 1an (a ≠ 0)

Знак степени

Отрицательное основание: чётный показатель — плюс, нечётный — минус.
(−2)^4 = 16, (−2)^3 = −8, −2^4 = −16.

Свойства

a^m · a^n = a^{m+n}
a^m : a^n = a^{m−n}
(a^m)^n = a^{mn}
(ab)^n = a^nb^n,  (a : b)^n = a^n : b^n

Стандартный вид

a · 10^n, где 1 ≤ a < 10, n — порядок.
Большое число — порядок положительный: 52 000 = 5,2 · 10^4.
Число меньше 1 — отрицательный: 0,052 = 5,2 · 10^−2.

Проверь себя перед контрольной

Ты умеешь: вычислять степени с натуральным, нулевым и отрицательным показателем; упрощать выражения по свойствам; приводить разные основания к одному (4 = 2^2, 27 = 3^3); записывать числа в стандартном виде и выполнять с ними действия. Если что-то забыл — вернись к теме: § 1, § 2, § 3.

Тест по главе

Типовые задания с решениями

1Вычислите: (−3)^3 + 2^4 − 5^0.
Показать решение
Шаг 1.(−3)^3 = (−3) · (−3) · (−3) = −27
Шаг 2.2^4 = 16
Шаг 3.5^0 = 1
Шаг 4.−27 + 16 − 1 = −12
Ответ: −12.
2Упростите: (a^3)^4 · a^−5 : a^2.
Показать решение
Шаг 1.(a^3)^4 = a^12 (показатели перемножаем).
Шаг 2.a^12 · a^−5 = a^{12 + (−5)} = a^7.
Шаг 3.a^7 : a^2 = a^5.
Ответ: a^5.
3Вычислите: 25 · 4384.
Показать решение
Шаг 1.Всё через основание 2: 4^3 = (2^2)^3 = 2^6, 8^4 = (2^3)^4 = 2^12.
Шаг 2.Числитель: 2^5 · 2^6 = 2^11.
Шаг 3.2^11 : 2^12 = 2^−1.
Шаг 4.2−1 = 12 = 0,5.
Ответ: 0,5.
4Вычислите: (13)−2 − (25)−1.
Показать решение
Шаг 1.(13)−2 = 32 = 9
Шаг 2.(25)−1 = 52 = 2,5
Шаг 3.9 − 2,5 = 6,5
Ответ: 6,5.
5Запишите в стандартном виде и укажите порядок: а) 372 000; б) 0,00045.
Показать решение
Шаг 1.а) Запятая сдвигается влево на 5 знаков: 372 000 = 3,72 · 10^5, порядок 5.
Шаг 2.б) Запятая сдвигается вправо на 4 знака: 0,00045 = 4,5 · 10^−4, порядок −4.
Ответ: а) 3,72 · 10^5, 5; б) 4,5 · 10^−4, −4.
6Найдите значение выражения и запишите в стандартном виде: (1,6 · 10^−3) · (5 · 10^7).
Показать решение
Шаг 1.Числа: 1,6 · 5 = 8.
Шаг 2.Степени: 10^−3 · 10^7 = 10^4.
Ответ: 8 · 10^4.
7Сравните: (−0,5)^7 и (−0,5)^6.
Показать решение
Шаг 1.Показатель 7 нечётный, основание отрицательное — (−0,5)^7 отрицательное.
Шаг 2.Показатель 6 чётный — (−0,5)^6 положительное.
Ответ: (−0,5)^7 < (−0,5)^6.
