Степень с целым показателем и её свойства

Что значат 5^0 и 5^−3? Показатель может быть нулём и отрицательным числом. Разберём, откуда берутся такие степени и как их вычислять.

Лестница степеней

Спускайся по лестнице: при уменьшении показателя на 1 значение делится на основание. Что будет, если пройти ниже показателя 1?

Получается, что 2^0 = 1, 2^−1 = 1/2, 2^−2 = 1/4. Именно так и определяют степени с нулевым и отрицательным показателем.

Определения

ОПРЕДЕЛЕНИЕ

Любое число a, не равное нулю, в нулевой степени равно единице: a^0 = 1, a ≠ 0.

ОПРЕДЕЛЕНИЕ

Степенью числа с целым отрицательным показателем называется число, обратное степени с тем же основанием и противоположным показателем:

a−n = 1an,  a ≠ 0.

Отрицательный показатель — не отрицательное число

2−3 = 18 — это положительное число. Минус в показателе «переворачивает» число, а не меняет знак.

Дробь в отрицательной степени

Дробь переворачиваем, а показатель меняем на противоположный: (23)−2 = (32)2 = 94.

Как вычислить степень с отрицательным показателем

АЛГОРИТМ
  1. 1)Назвать основание степени.
  2. 2)Записать число, ему обратное, — это новое основание.
  3. 3)Назвать показатель степени.
  4. 4)Записать противоположное ему число — новый показатель.
  5. 5)Найти значение степени с натуральным показателем.

Свойства степени с целым показателем

Все пять свойств из § 1 верны и для целых показателей (основания не равны нулю). Только теперь показатели могут быть отрицательными — следи за знаками при сложении и вычитании.

СВОЙСТВА
a^m · a^n = a^{m+n};   a^m : a^n = a^{m−n};   (a^m)^n = a^{mn};   (ab)^n = a^nb^n;   (a : b)^n = a^n : b^n

Частые ошибки

Отрицательный показатель сделал число отрицательным.
✗2−3 = −8
✓2−3 = 18
Нулевая степень — это не ноль.
✗7^0 = 0
✓7^0 = 1
Ошиблись в знаке при сложении показателей.
✗a^−2 · a^−3 = a^5
✓a^−2 · a^−3 = a^−5
Вычитание отрицательного числа: минус на минус даёт плюс.
✗b^4 : b^−2 = b^2
✓b^4 : b^−2 = b^6
Не перевернули дробь.
✗(13)−2 = 19
✓(13)−2 = 32 = 9

Тест

Тренажёр

Если ответ — дробь, впиши числитель в верхнее окошко, а знаменатель в нижнее. Минус ставь в числитель. Дробь должна быть несократимой.

Задачи посложнее

Сначала реши в тетради, потом открой решение и сверься.

1Вычислите: 2^−3 + 4^0 − 3^−2.
Показать решение
Шаг 1.2−3 = 123 = 18
Шаг 2.4^0 = 1
Шаг 3.3−2 = 132 = 19
Шаг 4.Общий знаменатель 72: 972 + 7272 − 872 = 7372 = 1172
Ответ: 1172.
2Упростите: a^−4 · a^7 : a^−2.
Показать решение
Шаг 1.Умножение: a^−4 · a^7 = a^{−4 + 7} = a^3.
Шаг 2.Деление: a^3 : a^−2 = a^{3 − (−2)}.
Шаг 3.3 − (−2) = 3 + 2 = 5.
Ответ: a^5.
3Вычислите: 9^−3 · 27^3.
Показать решение
Шаг 1.Приведём к основанию 3: 9 = 3^2, 27 = 3^3.
Шаг 2.9^−3 = (3^2)^−3 = 3^−6.
Шаг 3.27^3 = (3^3)^3 = 3^9.
Шаг 4.3^−6 · 3^9 = 3^{−6 + 9} = 3^3 = 27.
Ответ: 27.
4Сравните (−2)^−3 и (−2)^−4.
Показать решение
Шаг 1.(−2)−3 = 1(−2)3 = 1−8 = −18 — отрицательное число.
Шаг 2.(−2)−4 = 1(−2)4 = 116 — положительное число.
Шаг 3.Отрицательное число меньше положительного.
Ответ: (−2)^−3 < (−2)^−4.
