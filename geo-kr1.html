Шпаргалка

Отрезки

Если C лежит на AB, то AC + CB = AB. Середина делит отрезок пополам. Длина ломаной — сумма длин звеньев.

Углы

Если луч OC между сторонами ∠AOB, то ∠AOC + ∠COB = ∠AOB. Биссектриса делит угол пополам. Острый < 90°, прямой = 90°, тупой — от 90° до 180°, развёрнутый = 180°.

Окружность

Диаметр — хорда через центр, d = 2r. Диаметр — самая длинная хорда.

Перпендикуляры

Из точки на прямую можно опустить только один перпендикуляр. Две прямые, перпендикулярные третьей, не пересекаются.

Тест по главе

Типовые задачи с решениями

1Точка K лежит на отрезке MN, MK = 3,7 см, KN на 1,6 см длиннее. Найдите MN.
Показать решение
Шаг 1.KN = 3,7 + 1,6 = 5,3 см.
Шаг 2.MN = MK + KN = 3,7 + 5,3 = 9 см.
Ответ: 9 см.
2Разность двух смежных углов 40°. Найдите эти углы.
Показать решение
Шаг 1.Пусть меньший угол x, тогда больший x + 40°.
Шаг 2.Сумма смежных углов: x + x + 40° = 180°.
Шаг 3.2x = 140°, x = 70°.
Шаг 4.Больший: 70° + 40° = 110°.
Ответ: 70° и 110°.
3При пересечении двух прямых один угол в 2 раза меньше другого. Найдите все углы.
Показать решение
Шаг 1.Неравные углы при пересечении прямых — смежные: x + 2x = 180°.
Шаг 2.x = 60°, 2x = 120°.
Шаг 3.Вертикальные углы равны: ещё 60° и 120°.
Ответ: 60°, 120°, 60°, 120°.
4OC — биссектриса угла AOB, ∠AOB = 128°. Луч OD — дополнительный к лучу OC. Найдите ∠AOD.
Показать решение
Шаг 1.∠AOC = 128° : 2 = 64°.
Шаг 2.Лучи OC и OD дополнительные, значит ∠AOC и ∠AOD смежные.
Шаг 3.∠AOD = 180° − 64° = 116°.
Ответ: 116°.
5Сумма трёх углов, образованных при пересечении двух прямых, равна 250°. Найдите угол между прямыми.
Показать решение
Шаг 1.Все четыре угла вместе: два раза по 180° (две пары смежных) = 360°.
Шаг 2.Четвёртый угол: 360° − 250° = 110°.
Шаг 3.Смежный с ним: 180° − 110° = 70°. Меньший угол — 70°.
Ответ: 70°.
