Угол. Виды углов

Угол образуют два луча с общим началом. Научимся измерять углы в градусах, различать их виды и находить биссектрису.

ОпределениеТранспортирИзмерениеБиссектрисаТестЗадачи

Угол и его градусная мера

ОПРЕДЕЛЕНИЯ

Углом называется фигура, образованная двумя лучами с общим началом. Лучи — стороны угла, их общее начало — вершина. Обозначение: ∠AOB (вершина в середине) или ∠O.

Угол, стороны которого — дополнительные лучи, называется развёрнутым. Градус — это 1180 часть развёрнутого угла. 1° = 60′ (минут), 1′ = 60″ (секунд).

Транспортир: виды углов

Двигай красную точку — сторона OB поворачивается. Следи, как меняется вид угла. Около 90° и 180° точка «прилипает».

Аксиома измерения углов

АКСИОМА

Каждый угол имеет определённую градусную меру, большую нуля. Развёрнутый угол равен 180°. Если луч OC проходит между сторонами угла AOB, то ∠AOC + ∠COB = ∠AOB.

Двигай луч OC внутри угла AOB.

Равные углы и биссектриса

ОПРЕДЕЛЕНИЯ

Два угла равны, если их можно совместить наложением (у равных углов равные градусные меры).

Биссектрисой угла называется луч, который выходит из вершины угла и делит его на два равных угла.

В опыте выше поставь луч OC так, чтобы части стали равными, — это и будет биссектриса.

Тест

Задачи с решениями

1Луч OC проходит между сторонами угла AOB, равного 100°, причём ∠AOC = 3∠COB. Найдите эти углы.
Показать решение
Шаг 1.Пусть ∠COB = x, тогда ∠AOC = 3x.
Шаг 2.По аксиоме измерения углов: 3x + x = 100°.
Шаг 3.4x = 100°, x = 25°.
Ответ: ∠COB = 25°, ∠AOC = 75°.
2OK — биссектриса угла AOB, ∠AOK = 47°. Найдите ∠AOB. Какой это угол?
Показать решение
Шаг 1.Биссектриса делит угол пополам: ∠AOB = 2 · ∠AOK.
Шаг 2.2 · 47° = 94°.
Шаг 3.94° больше 90°, но меньше 180°.
Ответ: 94°, тупой угол.
3Выразите в минутах: а) 2,5°; б) 1°15′.
Показать решение
Шаг 1.а) 1° = 60′, поэтому 2,5° = 2,5 · 60′ = 150′.
Шаг 2.б) 1°15′ = 60′ + 15′ = 75′.
Ответ: 150′; 75′.
