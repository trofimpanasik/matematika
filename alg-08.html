Многочлен

Многочлен — это несколько одночленов, соединённых знаками «+» и «−». Научимся находить его члены, приводить подобные, записывать в стандартном виде и находить степень.

Что такое многочлен

ОПРЕДЕЛЕНИЕ

Многочленом называется сумма одночленов. Одночлены, из которых состоит многочлен, называются его членами.

Чтобы увидеть члены, мысленно поставь перед каждым одночленом знак «+»: a − b = a + (−b). Поэтому знак стоит перед членом и принадлежит ему. Нажимай «Дальше».

Двучлен и трёхчлен

Многочлен из двух членов — двучлен: 5x^2 + 2y^3. Из трёх — трёхчлен: a^2 − ab + b^2.

Одночлен — тоже многочлен

Одночлен считается многочленом, который состоит из одного члена. Например, 7xy^2.

Приведение подобных членов

Подобные члены имеют одинаковую буквенную часть: одни и те же буквы в одних и тех же степенях. Например, 5a^2 и −2a^2 подобны, а 5a^2 и 5a нет.

ПРАВИЛО

Чтобы привести подобные члены многочлена, нужно:

  1. 1)найти подобные члены и подчеркнуть их одинаково;
  2. 2)сложить их коэффициенты, а буквенную часть переписать без изменений.
5a^2 − 3a + 2a^2 = (5 + 2)a^2 − 3a = 7a^2 − 3a

Стандартный вид и степень многочлена

ОПРЕДЕЛЕНИЯ

Многочлен стандартного вида — это многочлен, у которого каждый член записан в стандартном виде и среди членов нет подобных.

Степень многочлена стандартного вида — наибольшая из степеней его членов.

Степень члена — сумма показателей всех его букв. Посмотри на маленькие значки над членами:

4x^3y4−2x^22+xy^45−70

Степени членов: 3 + 1 = 4; 2; 1 + 4 = 5; у числа степень 0. Наибольшая — 5, значит, это многочлен пятой степени.

Сначала приведи подобные

Степень ищут только у многочлена стандартного вида. У x^4 + 3x − x^4 степень не 4: после приведения подобных остаётся 3x, степень 1.

Значение многочлена

Сначала приведи многочлен к стандартному виду, потом подставляй число. Так считать гораздо меньше.

Найдём значение многочлена 3a^2 − 2a + 5 − 3a^2 + 4a при a = 7.

Шаг 1.3a^2 − 3a^2 = 0
Шаг 2.−2a + 4a = 2a
Шаг 3.Многочлен равен 2a + 5.
Шаг 4.2 · 7 + 5 = 14 + 5 = 19
Ответ: 19.

Частые ошибки

Сложили показатели степеней. При сложении подобных буквенная часть не меняется.
✗3x^2 + 2x^2 = 5x^4
✓3x^2 + 2x^2 = 5x^2
Сложили неподобные члены.
✗2x^2 + 3x = 5x^3
✓2x^2 + 3x — так и остаётся
Потеряли знак члена.
✗5a − 3b − 2a = 7a − 3b
✓5a − 3b − 2a = 3a − 3b
Нашли степень, не приведя подобные.
✗степень x^4 + 3x − x^4 равна 4
✓это 3x, степень 1

Тест

Тренажёр: приведи подобные

Запиши многочлен в стандартном виде: приведи подобные и расставь члены по убыванию степеней (порядок проверка не учитывает).

Задачи посложнее

Сначала реши в тетради, потом открой решение и сверься.

1Приведите многочлен к стандартному виду и найдите его степень: 3x^2y − 4xy + 2x^2y − x^2y + 6xy.
Показать решение
Шаг 1.Подобные 3x^2y, 2x^2y, −x^2y: (3 + 2 − 1)x^2y = 4x^2y
Шаг 2.Подобные −4xy и 6xy: (−4 + 6)xy = 2xy
Шаг 3.Многочлен: 4x^2y + 2xy
Шаг 4.Степени членов: 2 + 1 = 3 и 1 + 1 = 2. Наибольшая 3.
Ответ: 4x^2y + 2xy, степень 3.
2Найдите значение многочлена 5m^2 − 3m + 4 − 5m^2 + 8m при m = −3.
Показать решение
Шаг 1.5m^2 − 5m^2 = 0
Шаг 2.−3m + 8m = 5m
Шаг 3.Многочлен равен 5m + 4.
Шаг 4.5 · (−3) = −15
Шаг 5.−15 + 4 = −11
Ответ: −11.
3При каком значении a значение многочлена 2a^2 + 3a − 2a^2 + a − 8 равно нулю?
Показать решение
Шаг 1.2a^2 − 2a^2 = 0
Шаг 2.3a + a = 4a
Шаг 3.Многочлен равен 4a − 8. Решаем уравнение 4a − 8 = 0.
Шаг 4.4a = 8
Шаг 5.a = 8 : 4 = 2
Ответ: при a = 2.
4Докажите, что многочлен x^2 + 4 − 3x^2 + 2x^2 + 1 при любом x принимает одно и то же значение.
Показать решение
Шаг 1.Подобные x^2, −3x^2, 2x^2: (1 − 3 + 2)x^2 = 0
Шаг 2.4 + 1 = 5
Шаг 3.Многочлен равен 5, в нём нет буквы x.
Ответ: при любом x значение равно 5.
