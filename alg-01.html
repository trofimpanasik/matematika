Степень с натуральным показателем и её свойства

Степень — короткая запись произведения одинаковых множителей. Разберём, как её вычислять, и пять свойств, которые позволяют считать со степенями, не раскрывая их.

Что такое степень

ОПРЕДЕЛЕНИЕ

Степенью числа a с натуральным показателем n, большим 1, называется произведение n множителей, каждый из которых равен a. Если n = 1, то a^1 = a.

a^n = a · a · … · a  (n множителей)

В записи a^n число a — основание степени, n — показатель. Показатель говорит, сколько раз основание взято множителем. Нажимай «Дальше».

Знак степени

Положительное основание

Любая степень положительного числа положительна: 3^4 = 81, 0,5^3 = 0,125.

Ноль

0^n = 0 при любом натуральном n: 0^5 = 0.

Отрицательное основание, чётный показатель

Минусы разбиваются на пары, и результат положительный: (−2)^4 = 16.

Отрицательное основание, нечётный показатель

Один минус остаётся без пары, результат отрицательный: (−2)^3 = −8.

Скобки важны

(−3)^2 = (−3) · (−3) = 9, а −3^2 = −(3 · 3) = −9. Без скобок в степень возводится только 3, а минус ставится перед результатом.

Пять свойств степени

СВОЙСТВА
  1. 1)a^n · a^m = a^{n+m} — при умножении степеней с одинаковыми основаниями показатели складываются;
  2. 2)a^n : a^m = a^{n−m} (a ≠ 0, n > m) — при делении показатели вычитаются;
  3. 3)(a^n)^m = a^{nm} — при возведении степени в степень показатели перемножаются;
  4. 4)(ab)^n = a^n · b^n — степень произведения равна произведению степеней;
  5. 5)(a : b)^n = a^n : b^n (b ≠ 0) — степень частного равна частному степеней.

Почему так? Распишем степени через множители. Выбери свойство:

Модель из плиток

Каждая плитка — один множитель a. Выбери действие и двигай ползунки: видно, почему показатели складываются, вычитаются или перемножаются.

Частые ошибки

Перемножили показатели при умножении. Их нужно складывать.
✗a^3 · a^4 = a^12
✓a^3 · a^4 = a^7
Перемножили основания. Основание остаётся прежним.
✗2^3 · 2^4 = 4^7
✓2^3 · 2^4 = 2^7
Сложили показатели при возведении степени в степень.
✗(x^3)^4 = x^7
✓(x^3)^4 = x^12
Разделили показатели при делении.
✗b^8 : b^2 = b^4
✓b^8 : b^2 = b^6
Умножили основание на показатель.
✗5^2 = 10
✓5^2 = 5 · 5 = 25
Потеряли скобки: минус не возводится в степень.
✗−2^4 = 16
✓−2^4 = −16

Тест

Тренажёр

Впиши ответ в окошко. В режимах со степенями окошко стоит сверху, на месте показателя.

Задачи посложнее

Сначала реши в тетради, потом открой решение и сверься.

1Вычислите: 2^10 : 2^7 · 2^2.
Показать решение
Шаг 1.Действия выполняем по порядку, слева направо. Деление: 2^10 : 2^7 = 2^{10−7} = 2^3.
Шаг 2.Умножение: 2^3 · 2^2 = 2^{3+2} = 2^5.
Шаг 3.2^5 = 2 · 2 · 2 · 2 · 2 = 32.
Ответ: 32.
2Упростите: (x^3)^4 · x^2 : x^10.
Показать решение
Шаг 1.Степень степени: (x^3)^4 = x^{3·4} = x^12.
Шаг 2.Умножение: x^12 · x^2 = x^14.
Шаг 3.Деление: x^14 : x^10 = x^4.
Ответ: x^4.
3Вычислите: 4^5 · 2^3 : 8^4.
Показать решение
Шаг 1.Основания разные. Запишем всё как степени двойки: 4 = 2^2, 8 = 2^3.
Шаг 2.4^5 = (2^2)^5 = 2^10.
Шаг 3.8^4 = (2^3)^4 = 2^12.
Шаг 4.2^10 · 2^3 = 2^13.
Шаг 5.2^13 : 2^12 = 2^1 = 2.
Ответ: 2.
4Вычислите удобным способом: 0,25^7 · 4^7.
Показать решение
Шаг 1.Показатели одинаковые, поэтому по свойству 4 основания можно перемножить: 0,25^7 · 4^7 = (0,25 · 4)^7.
Шаг 2.0,25 · 4 = 1.
Шаг 3.1^7 = 1.
Ответ: 1.
