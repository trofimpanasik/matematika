Сложение и вычитание многочленов

Чтобы сложить или вычесть многочлены, нужно раскрыть скобки и привести подобные члены. Главное — правильно поступить со знаками.

Правило скобокРазборОшибкиТестТренажёрЗадачи

Как раскрывать скобки

ПЕРЕД СКОБКАМИ «+»
  1. 1)опускаем скобки и знак «+»;
  2. 2)знаки в скобках не меняем.
a + (b − c) = a + b − c
ПЕРЕД СКОБКАМИ «−»
  1. 1)опускаем скобки и знак «−»;
  2. 2)знак каждого члена в скобках меняем на противоположный.
a − (b − c) = a − b + c

После раскрытия скобок приводим подобные члены. Чтобы найти сумму или разность многочленов, каждый многочлен берём в скобки.

Разбор по шагам

Смотри, как меняются знаки после минуса: такие члены подсвечены красным.

Почему знаки меняются

Вычесть многочлен — значит прибавить противоположный ему: −(b − c) = −b + c. Каждый член умножается на −1.

Обратно: взять в скобки

Если ставим «−» перед скобками, знаки внутри тоже меняем: a − b + c = a − (b − c). Проверить легко — раскрой скобки.

Частые ошибки

Поменяли знак только у первого члена в скобках.
✗x − (y − 3) = x − y − 3
✓x − (y − 3) = x − y + 3
Поменяли знаки, хотя перед скобками «+».
✗a + (b − 2) = a − b + 2
✓a + (b − 2) = a + b − 2
Вычитаемое записали без скобок.
✗3a − 2a + 5 = a + 5 вместо разности 3a и 2a + 5
✓3a − (2a + 5) = a − 5

Тест

Тренажёр

Раскрой скобки, приведи подобные и запиши ответ многочленом стандартного вида.

Задачи посложнее

1Упростите выражение (2x^2 − 3x + 1) − (x^2 − 3x − 4) + (5 − x^2).
Показать решение
Шаг 1.Первые скобки (перед ними ничего нет): 2x^2 − 3x + 1
Шаг 2.Перед вторыми скобками «−», знаки меняем: −x^2 + 3x + 4
Шаг 3.Перед третьими «+», знаки не меняем: + 5 − x^2
Шаг 4.2x^2 − x^2 − x^2 = 0
Шаг 5.−3x + 3x = 0
Шаг 6.1 + 4 + 5 = 10
Ответ: 10.
2Решите уравнение (5x − 3) − (2x + 6) = 12.
Показать решение
Шаг 1.5x − 3 − 2x − 6 = 12
Шаг 2.5x − 2x = 3x; −3 − 6 = −9
Шаг 3.3x − 9 = 12
Шаг 4.3x = 12 + 9 = 21
Шаг 5.x = 21 : 3 = 7
Ответ: x = 7.
3Найдите многочлен P, для которого P + (3a^2 − 2a) = 5a^2 + a − 4.
Показать решение
Шаг 1.Неизвестное слагаемое = сумма − известное слагаемое: P = (5a^2 + a − 4) − (3a^2 − 2a)
Шаг 2.5a^2 + a − 4 − 3a^2 + 2a
Шаг 3.5a^2 − 3a^2 = 2a^2; a + 2a = 3a
Ответ: P = 2a^2 + 3a − 4.
4Докажите, что сумма трёх последовательных натуральных чисел делится на 3.
Показать решение
Шаг 1.Пусть числа n, n + 1, n + 2.
Шаг 2.Сумма: n + (n + 1) + (n + 2) = n + n + 1 + n + 2
Шаг 3.n + n + n = 3n; 1 + 2 = 3. Сумма равна 3n + 3.
Шаг 4.3n + 3 = 3(n + 1) — это число, умноженное на 3.
Значит, сумма делится на 3.
