Умножение многочленов

Каждый член первого многочлена умножаем на каждый член второго, а потом приводим подобные. Стрелки помогут ничего не пропустить.

ПравилоРазборМодель из плитокОшибкиТренажёрЗадачи

Правило

ПРАВИЛО

Чтобы умножить многочлен на многочлен, нужно:

  1. 1)умножить каждый член одного многочлена на каждый член другого многочлена;
  2. 2)полученные произведения сложить.
(a + b)(c + d) = ac + ad + bc + bd

Откуда это правило? Обозначим вторую скобку одной буквой и дважды применим распределительный закон: (a + b)(c + d) = a(c + d) + b(c + d) = ac + ad + bc + bd.

Сколько произведений?

Если в первом многочлене m членов, а во втором n, то до приведения подобных получится m · n произведений. Для двух двучленов — 4.

Порядок обхода

Берём первый член первой скобки и по очереди умножаем на все члены второй. Потом второй член — и снова на все.

Разбор по шагам

Стрелки первого члена идут сверху, второго — снизу. Цвет произведения совпадает с цветом члена первой скобки.

Модель из плиток

Прямоугольник со сторонами x + a и x + b складывается из плиток: большой квадрат x^2, полоски площадью x и единичные квадратики. Сторона x нарочно не целая: это буква, её длину мы не знаем.

Частые ошибки

Перемножили только первые и последние члены.
✗(x + 3)(x + 2) = x^2 + 6
✓x^2 + 2x + 3x + 6 = x^2 + 5x + 6
Ошиблись в знаке при подобных.
✗(x − 3)(x + 2) = x^2 + x − 6
✓x^2 + 2x − 3x − 6 = x^2 − x − 6
Пропустили одно из произведений с трёхчленом.
✗(a + 1)(a^2 − a + 1) = a^3 + 1 − a
✓6 произведений: a^3 − a^2 + a + a^2 − a + 1 = a^3 + 1

Тренажёр

Перемножь многочлены и приведи подобные. Ответ — многочлен стандартного вида.

Задачи посложнее

1Упростите выражение (x + 4)(x − 1) − x(x + 3).
Показать решение
Шаг 1.(x + 4)(x − 1) = x^2 − x + 4x − 4
Шаг 2.−x + 4x = 3x, получаем x^2 + 3x − 4
Шаг 3.x(x + 3) = x^2 + 3x
Шаг 4.x^2 + 3x − 4 − x^2 − 3x
Шаг 5.x^2 − x^2 = 0; 3x − 3x = 0; остаётся −4.
Ответ: −4.
2Решите уравнение (x + 2)(x + 5) − x^2 = 24.
Показать решение
Шаг 1.(x + 2)(x + 5) = x^2 + 5x + 2x + 10 = x^2 + 7x + 10
Шаг 2.x^2 + 7x + 10 − x^2 = 24
Шаг 3.7x + 10 = 24
Шаг 4.7x = 14
Шаг 5.x = 2
Ответ: x = 2.
3Докажите тождество (a − 1)(a^2 + a + 1) = a^3 − 1.
Показать решение
Шаг 1.a · a^2 = a^3; a · a = a^2; a · 1 = a
Шаг 2.−1 · a^2 = −a^2; −1 · a = −a; −1 · 1 = −1
Шаг 3.a^3 + a^2 + a − a^2 − a − 1
Шаг 4.a^2 − a^2 = 0; a − a = 0
Левая часть равна a^3 − 1, тождество доказано.
4Длина прямоугольника на 3 см больше ширины. Если ширину увеличить на 2 см, а длину на 1 см, площадь увеличится на 26 см². Найдите стороны прямоугольника.
Показать решение
Шаг 1.Ширина x см, длина x + 3 см. Площадь x(x + 3) = x^2 + 3x.
Шаг 2.Новые стороны x + 2 и x + 4. Площадь (x + 2)(x + 4) = x^2 + 4x + 2x + 8 = x^2 + 6x + 8.
Шаг 3.Разность площадей: x^2 + 6x + 8 − x^2 − 3x = 3x + 8.
Шаг 4.3x + 8 = 26, 3x = 18, x = 6.
Шаг 5.Длина 6 + 3 = 9.
Ответ: 6 см и 9 см.
