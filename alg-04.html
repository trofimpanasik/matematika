Числовые выражения и выражения с переменными

Выражение — это запись решения задачи. В числовом выражении только числа, в выражении с переменными есть ещё буквы. Научимся находить значения выражений и выяснять, при каких значениях букв выражение имеет смысл.

Числовые выражения

ОПРЕДЕЛЕНИЯ

Числовое выражение — это запись, составленная из чисел, знаков действий и скобок.

Значение числового выражения — это число, полученное в результате выполнения указанных в выражении действий.

Задача: автобус шёл 3 ч со скоростью 56 км/ч, а потом 4 ч со скоростью на 6 км/ч больше. Какова длина маршрута? Выражение: 56 · 3 + (56 + 6) · 4. Порядок действий: сначала скобки, потом умножение и деление, потом сложение и вычитание. Нажимай «Дальше».

Выражения с переменными

ОПРЕДЕЛЕНИЕ

Выражение с переменными — это запись, содержащая числа, знаки действий, скобки и переменные, обозначенные буквами. Если вместо переменных подставить числа, получится числовое выражение; его значение — значение выражения с переменными при этих значениях переменных.

Килограмм груш стоит 5 р., килограмм яблок — y р. Сколько стоят 2 кг груш и 3 кг яблок? Выражение: 2 · 5 + 3y. Двигай ползунок — меняй цену яблок.

Отрицательное число подставляй в скобках

При x = −3: x^2 = (−3)^2 = 9, а не −3^2 = −9. И 5 − x = 5 − (−3) = 8.

Область определения выражения

ОПРЕДЕЛЕНИЕ

Область определения выражения с переменной — все значения переменной, при которых выражение имеет смысл (его значение можно найти).

Выражение (4 + x) · 3x^3 + 2 имеет смысл при любом x: сложение, умножение и степень выполнимы всегда. А в выражении (4 + x) : (2 − x) есть деление на выражение с переменной. Двигай x и следи, что происходит при x = 2.

Вывод

Делитель 2 − x обращается в ноль при x = 2, а на ноль делить нельзя. Область определения выражения (4 + x) : (2 − x) — все числа, кроме 2. На числовой прямой это прямая с «выколотой» точкой 2.

Частые ошибки

Сложили раньше, чем умножили.
✗2 + 3 · 4 = 20
✓2 + 3 · 4 = 14
Подставили отрицательное число без скобок.
✗x = −2: x^2 = −4
✓(−2)^2 = 4
Решили, что ноль не может быть значением переменной. Нельзя только делить на ноль.
✗5x не имеет смысла при x = 0
✓5 · 0 = 0, смысл есть
Искали запрещённые значения в делимом, а не в делителе.
✗(x − 3) : (x + 1): кроме 3
✓все числа, кроме −1

Тест

Тренажёр

Подставь число и найди значение выражения или найди число, при котором выражение не имеет смысла.

Задачи посложнее

Сначала реши в тетради, потом открой решение и сверься.

1Найдите значение выражения 2a^2 − ab^2 − 3 при a = 4, b = −2.
Показать решение
Шаг 1.Подставляем: 2 · 4^2 − 4 · (−2)^2 − 3.
Шаг 2.Степени: 4^2 = 16, (−2)^2 = 4.
Шаг 3.Умножение: 2 · 16 = 32, 4 · 4 = 16.
Шаг 4.32 − 16 − 3 = 13.
Ответ: 13.
2Найдите область определения выражения 7 : (x^2 − 9).
Показать решение
Шаг 1.Выражение не имеет смысла, когда делитель равен нулю: x^2 − 9 = 0.
Шаг 2.x^2 = 9.
Шаг 3.Это верно при x = 3 и при x = −3, ведь (−3)^2 = 9.
Ответ: все числа, кроме 3 и −3.
3Составьте выражение: тетрадь стоит a р., а ручка на 3 р. дороже. Сколько стоят 5 тетрадей и 2 ручки? Найдите значение при a = 1,5.
Показать решение
Шаг 1.Ручка стоит a + 3 р.
Шаг 2.Покупка: 5a + 2(a + 3) р.
Шаг 3.При a = 1,5: 5 · 1,5 + 2 · (1,5 + 3) = 7,5 + 2 · 4,5.
Шаг 4.7,5 + 9 = 16,5.
Ответ: 5a + 2(a + 3); 16,5 р.
