Умножение и деление многочлена на одночлен

Оба действия устроены одинаково: одночлен по очереди «встречается» с каждым членом многочлена.

Умножение одночлена на многочлен

ПРАВИЛО

Чтобы умножить одночлен на многочлен, нужно:

  1. 1)умножить одночлен на каждый член многочлена;
  2. 2)полученные произведения сложить.
2a(a^2 + 3a − 1) = 2a · a^2 + 2a · 3a − 2a · 1 = 2a^3 + 6a^2 − 2a

Член многочлена берётся вместе со своим знаком. В многочлене 4x − 7y второй член равен −7y, поэтому умножать надо на −7y.

Сколько членов получится?

Столько же, сколько в многочлене: одночлен умножается на каждый член, и подобных среди произведений не появляется.

Какая будет степень?

Степени складываются: 3x^2 · (x^4 − 2x + 1) имеет степень 2 + 4 = 6, старший член 3x^6.

Почему это работает

Это распределительный закон a(b + c + d) = ab + ac + ad. Прямоугольник высотой a разбит на три куска: площадь всего прямоугольника равна сумме площадей кусков. Подвигай ползунки.

Деление многочлена на одночлен

Деление обратно умножению. Мы получили 2x^2 · (2x^2 − 3x + 4) = 4x^4 − 6x^3 + 8x^2. Значит, (4x^4 − 6x^3 + 8x^2) : (2x^2) = 2x^2 − 3x + 4: каждый член разделился на 2x^2 отдельно.

ПРАВИЛО

Чтобы разделить многочлен на одночлен, нужно:

  1. 1)разделить каждый член многочлена на этот одночлен;
  2. 2)полученные частные сложить.
(4x^4 − 6x^3 + 8x^2) : (2x^2) = 2x^2 − 3x + 4

При делении одночленов числа делятся, а показатели одинаковых букв вычитаются: x^7 : x^3 = x^4, потому что 7 − 3 = 4.

Проверка умножением

Умножь ответ на делитель — должен получиться исходный многочлен.

Частное не всегда многочлен

(4x^3 + 2x) : x^2: 2x : x^2 одночленом не будет. В наших заданиях каждый член делится нацело.

Частые ошибки

Умножили не на все члены.
✗3x(x + 2) = 3x^2 + 2
✓3x(x + 2) = 3x^2 + 6x
Потеряли знак: минус на минус даёт плюс.
✗−2a(a − 4) = −2a^2 − 8a
✓−2a(a − 4) = −2a^2 + 8a
Написали 0 вместо 1, когда член делится сам на себя.
✗(5x^2 + x) : x = 5x
✓(5x^2 + x) : x = 5x + 1
Показатели перемножили, а надо сложить.
✗x^2 · x^3 = x^6
✓x^2 · x^3 = x^5
Показатели разделили, а надо вычесть.
✗x^6 : x^2 = x^3
✓x^6 : x^2 = x^4

Тренажёр

Каждый раз новый пример. Впиши ответ многочленом стандартного вида. Если не получается, открой пошаговое решение.

Задачи посложнее

1Упростите выражение 2a(a − 3) − a(2a + 1).
Показать решение
Шаг 1.2a(a − 3) = 2a^2 − 6a
Шаг 2.a(2a + 1) = 2a^2 + a
Шаг 3.(2a^2 − 6a) − (2a^2 + a) = 2a^2 − 6a − 2a^2 − a
Шаг 4.2a^2 − 2a^2 = 0; −6a − a = −7a
Ответ: −7a.
2Упростите выражение (10x^3 − 5x^2) : (5x^2) + (3 − 2x).
Показать решение
Шаг 1.10x^3 : (5x^2) = 2x
Шаг 2.−5x^2 : (5x^2) = −1
Шаг 3.2x − 1 + 3 − 2x
Шаг 4.2x − 2x = 0; −1 + 3 = 2
Ответ: 2.
3Решите уравнение x(x + 4) − x(x − 2) = 18.
Показать решение
Шаг 1.x(x + 4) = x^2 + 4x
Шаг 2.x(x − 2) = x^2 − 2x
Шаг 3.x^2 + 4x − x^2 + 2x = 18
Шаг 4.6x = 18
Шаг 5.x = 18 : 6 = 3
Ответ: x = 3.
4Найдите значение выражения (6a^3b − 9a^2b^2) : (3a^2b) + 3b при a = 7, b = −5.
Показать решение
Шаг 1.6a^3b : (3a^2b) = 2a
Шаг 2.−9a^2b^2 : (3a^2b) = −3b
Шаг 3.2a − 3b + 3b = 2a. Значение b не нужно.
Шаг 4.2 · 7 = 14
Ответ: 14.
5Докажите, что значение выражения (12y^4 − 8y^3) : (4y^2) − y(3y − 2) не зависит от y (y ≠ 0).
Показать решение
Шаг 1.12y^4 : (4y^2) = 3y^2
Шаг 2.−8y^3 : (4y^2) = −2y
Шаг 3.y(3y − 2) = 3y^2 − 2y
Шаг 4.3y^2 − 2y − 3y^2 + 2y
Шаг 5.3y^2 − 3y^2 = 0; −2y + 2y = 0
Значение равно 0 при любом y ≠ 0.
