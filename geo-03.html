Прямая. Луч. Отрезок. Ломаная

Основные фигуры планиметрии и их свойства: аксиома прямой, лучи и отрезки, измерение отрезков, ломаные и многоугольники.

ПрямаяЛучОтрезокЛоманаяТестЗадачи

Прямая

АКСИОМА ПРЯМОЙ

Через любые две точки проходит прямая, и притом только одна.

Отсюда следует: две различные прямые имеют не более одной общей точки. Если бы общих точек было две, через них прошли бы две прямые — а по аксиоме это невозможно. Двигай точку C: лежит ли она на прямой AB?

Луч

ОПРЕДЕЛЕНИЕ

Точка O разбивает прямую на две части. Каждая часть вместе с точкой O называется лучом, точка O — началом луча. Два луча с общим началом, лежащие на одной прямой, называются дополнительными.

Луч бесконечен в одну сторону. Его называют по началу и ещё одной точке: луч OA (начало всегда пишут первым).

Отрезок и его длина

ОПРЕДЕЛЕНИЯ

Отрезком называется часть прямой, ограниченная двумя точками — концами отрезка.

Два отрезка называются равными, если их можно совместить наложением. Серединой отрезка называется точка, которая делит его на два равных отрезка.

АКСИОМА ИЗМЕРЕНИЯ ОТРЕЗКОВ

Каждый отрезок имеет определённую длину, большую нуля. Если точка C лежит на отрезке AB, то AC + CB = AB.

Двигай точку C по отрезку: части меняются, а их сумма — нет. Около середины точка «прилипает».

Ломаная и многоугольник

ОПРЕДЕЛЕНИЯ

Ломаная — фигура из отрезков (звеньев), где конец каждого звена — начало следующего, а соседние звенья не лежат на одной прямой. Длина ломаной — сумма длин её звеньев.

Ломаная замкнутая, если её концы совпадают; простая — если она не имеет самопересечений. Простая замкнутая ломаная называется многоугольником, сумма длин его сторон — периметром.

Двигай вершины ломаной. Кнопкой можно её замкнуть.

Тест

Задачи с решениями

1Точка C лежит на отрезке AB длиной 12 см, AC = 2CB. Найдите AC и CB.
Показать решение
Шаг 1.Пусть CB = x см, тогда AC = 2x см.
Шаг 2.По аксиоме измерения: AC + CB = AB, то есть 2x + x = 12.
Шаг 3.3x = 12, x = 4.
Ответ: CB = 4 см, AC = 8 см.
2Точки A, B, C лежат на одной прямой, AB = 7 см, BC = 3 см. Найдите AC. Рассмотрите все случаи.
Показать решение
Шаг 1.Если C лежит между A и B: AC = AB − BC = 7 − 3 = 4 см.
Шаг 2.Если B лежит между A и C: AC = AB + BC = 7 + 3 = 10 см.
Шаг 3.A между B и C быть не может: тогда BC > AB, а 3 < 7.
Ответ: 4 см или 10 см.
3Периметр треугольника 24 см, две стороны 7 см и 9 см. Найдите третью сторону.
Показать решение
Шаг 1.Периметр — сумма всех сторон: 7 + 9 + x = 24.
Шаг 2.16 + x = 24, x = 8.
Ответ: 8 см.
